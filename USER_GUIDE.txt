le-fi - send or receive a file, anywhere
========================================

le-fi sends a file (or a folder) directly between two computers, in
either direction, even behind NAT or a firewall. No account, no
signup, no cloud storage in the middle. Sending a file copies it -
nothing is deleted or moved on your end.

The other person doesn't need to install anything: a browser is
enough, or curl/wget if they'd rather use a terminal.


RECEIVING A FILE
----------------

1. Open a terminal.

2. Run this, naming the file you're about to receive:

       ./le-fi > myfile.zip

3. le-fi prints a URL plus ready-to-paste curl/wget/le-fi commands.

4. Send those to whoever's sending you the file, however you'd
   normally reach them.

5. They open the link in a browser and drop the file on, or run one
   of the commands you sent. Either way it streams straight to you,
   and le-fi tells you when it's done.


SENDING A FILE
--------------

Already got a command from someone? Paste it in and run it.

Starting the send yourself:

       ./le-fi myfile.zip          a single file
       ./le-fi my-folder/          a folder, sent as a .tar.gz
       ./le-fi < myfile.zip        same as the first, piped in

le-fi prints a link - send it over. The other person can open it in a
browser, use curl/wget, or use le-fi if they have it. If a download
drops mid-transfer, le-fi keeps waiting for a retry; it only exits
once a transfer actually succeeds.


IS THIS SAFE?
-------------

The connection is HTTPS-encrypted end to end. If both sides are using
le-fi, it also checksums the transfer and flags any mismatch.

The one real thing to know: the URL le-fi prints works for anyone who
has it, for as long as the transfer window stays open (usually well
under a minute). Don't post it publicly - treat it as a one-time
link. It stops working once the transfer completes, or Ctrl+C ends it
early.

No accounts, no phoning home, no crash reports or usage stats sent
anywhere - confirmed by watching every network connection le-fi
makes, not just assumed.


WHAT'S ACTUALLY HAPPENING
--------------------------

le-fi uses Cloudflare's Quick Tunnel feature, the same one Cloudflare
gives away for free through their own cloudflared tool - built in
here directly, so there's nothing extra to install.

Each transfer gets a fresh, random, disposable URL
(https://some-random-words.trycloudflare.com), unrelated to any
account and discarded after use.


IF SOMETHING GOES WRONG
------------------------

- First connection attempt fails outright? Wait a few seconds and
  retry - a freshly created address takes a moment to propagate
  across Cloudflare's network.

- Got the direction backwards (pushed to something waiting to send,
  or the reverse)? le-fi detects it and prints the fix.

- One transfer per run. Run le-fi again for another - you'll get a
  new address each time.
